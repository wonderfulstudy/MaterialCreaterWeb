# 「我的」页改版 · 视觉规格（375px 画板 / 750rpx）

> 落地对象：`MaterialCreaterWeb/src/pages/profile/index.tsx`（现行 75 行，将被本规格替换）。
> 视觉样稿：`MaterialCreaterWeb/docs/profile-redesign.html`（四状态同页，375px 画板）。
> 换算基准：**1px = 2rpx**（750rpx 设计宽度）。下表中「样稿 px」为 HTML 中的实测值，「rpx」为前端落地值。
> 颜色、圆角、字号**只允许**取自第 1 节令牌表与第 2 节字号阶梯，不自创。

## 6. 交互与反馈

### 6.1 按下态

- 所有按钮：`active` 时 `opacity: .86`，`transition: .15s ease`（`variables.scss` $transition-fast），不做位移/缩放。
- 功能入口行：`active` 时整行背景 `#f0f0f2`，圆角随卡片 28rpx（首尾行只圆对应两角），文案颜色不变。
- 头像/二维码不做点击反馈（二维码仅在「保存到相册」「更换」上响应）。

### 6.2 加载态

| 场景 | 表现 |
| --- | --- |
| 静默登录中（首次进页面） | 身份卡昵称位显示 `正在登录…`（34rpx/500/muted），无主按钮，不阻塞页面滚动与功能入口点击（auth-contract §7） |
| 点击「微信一键登录」后 | 按钮保持 96rpx/64rpx 尺寸，底色不变，透明度 0.7，文案改 `登录中…`，期间禁用点击 |
| 导入二维码中 | 空态主按钮文案改 `正在导入…`，禁用点击，占位框不变；成功后整体切到状态 04 |
| 保存到相册中 | 主按钮文案改 `保存中…`，禁用；成功后用微信原生 `showToast` 居中提示 `已保存到相册` |

### 6.3 成功反馈

- 导入成功：二维码卡 meta 由「未导入」变「已导入」，说明句与三按钮出现（不弹窗、不跳转）。
- 保存成功：原生 toast，1.5s 自动消失；失败（无相册权限）用原生 `showModal`，标题 `保存失败`，内容 `请在设置里允许保存到相册`，确认按钮 `知道了`。

### 6.4 失败提示位置与文案

| 失败类型 | 位置 | 文案 | 颜色 |
| --- | --- | --- | --- |
| 登录失败（400 invalid_payload / 500 / 429） | 身份卡副行位置（昵称下方 8rpx 处），替换 openid 行 | `登录失败，请重试` / `服务异常` / `操作太频繁，请稍后再试` | red `#ff383c`，22rpx |
| 微信服务异常（502） | 同上 | `微信服务异常` | red |
| 登录失败后的按钮 | 身份卡右侧主按钮 | `重新登录` | 同主按钮 |
| 选图取消 | 无提示，保持空态 | — | — |
| 图片格式/体积不合法 | **占位框下方 8rpx、居中**（占位框与主按钮之间） | `导入失败，请重新选择二维码截图` | red，22rpx |
| 图片非二维码/识别失败 | 同上 | `没识别到二维码，换一张试试` | red，22rpx |
| 二维码模块未登录 | 占位框内唯一文案 | `登录后可管理你的二维码`（不再显示错误行） | muted |

规则：错误行只在**当前卡片内部**出现，不遮挡按钮、不挤压操作步骤区（步骤区随卡片高度自然下移）；同一次错误只显示一行，重试成功后立即清除。

## 7. 前端验收要点（可机械核对，共 12 条）

1. 模块顺序固定为：标题 → 身份卡 → 二维码卡 → 功能入口卡 → 版本 footer → TabBar；缺失、调序或在中间插入模块即为不合格。
2. 内容区左右内边距 28rpx（内容宽 694rpx），页面无横向滚动（`scrollWidth === clientWidth`）。
3. 身份卡 `min-height ≥ 160rpx`、内边距 32rpx、圆角 28rpx、底色 `#ffffff`；头像 96×96rpx 且为全圆（`border-radius ≥ 999rpx` 或 50%）。
4. 身份卡已登录态必须同时出现：昵称 34rpx/600；green `#34c759` 的「微信已登录」+ 10rpx 圆点；`openid …jklmn`（22rpx/muted，仅 6 位尾号）；blue `#0088ff` 的「编辑昵称头像」。登录失败时该卡副行（openid 位置）显示 `登录失败，请重试` 且为 red `#ff383c`。
5. 卡片垂直间距：身份卡→二维码卡 24rpx、二维码卡→功能卡 24rpx、功能卡→footer 40rpx。
6. 二维码占位框与二维码本体均为 420×420rpx；已导入态白底框宽 476rpx（420 + 28×2）且内边距 28rpx；导入失败提示只在占位框下方 8rpx、居中出现，颜色 `#ff383c`。
7. 按钮尺寸：主按钮高 96rpx、次按钮高 64rpx、圆角均 48rpx；主按钮底 `#ecc97a`、字 `#1c1c1e`/28rpx/600；次按钮底 `#f2f2f5`、字 26rpx/500。
8. 功能入口卡恰好 3 行，行高 108rpx；行间分隔线 2rpx `#f0f0f2` 且左缩进 76rpx；每行图标 56×56rpx（圆角 14rpx）+ 文案 28rpx + 右侧箭头。
9. footer 文案逐字为 `彩店管理助手 · v1.0.0`，22rpx / muted / 居中，距功能卡 40rpx。
10. TabBar 高 150rpx、底色 `#f2f2f5`；第三项「我的」选中：胶囊 120×56rpx 底 `#ecc97a`，标签 `#1c1c1e` + 600（26rpx），图标 44rpx。
11. 四状态文案与第 5 节逐字一致（含全角标点、「…」「— 未登录 —」「→」「「」」），无错字；关键文案不折行溢出（按钮文案单行）。
12. 全部十六进制色值 ⊆ 第 1 节 10 个令牌；不出现 rgba/hsl/渐变/投影色，不引入外链图片、字体或 CDN。

## 8. 已知取舍（需评审确认）

1. **未登录头像**：现页面头像底与首字色（见 `profile/index.module.scss` 的 `.avatar` 规则：浅黄底 + 深黄字）均不在本次令牌表内，故样稿改为「已登录 `#ecc97a` + ink 文字 / 未登录 `#f2f2f5` + muted 人形」。若评审要求保留原浅黄底，令牌表需追加该两色（取值见该规则原值）。
2. **TabBar 与箭头的既有灰**：现组件未选中标签与菜单箭头各带一个自有灰（见 `TabBar/index.module.scss` 的 `.label` 与 `profile/index.module.scss` 的 `.menuArrow`），均不在令牌表内；样稿统一改用 muted `#8e8e93`。前端沿用现组件时以原值为准，样稿与实现在这两处允许 1 个色号的差异。
3. **状态 02 与 03 视觉主体相同**：模块顺序固定且二者同属「已登录 + 未导入」，样稿以状态段标题区分侧重（02 看身份卡，03 看二维码模块）。若需要更强区分，可把 02 的二维码卡换成「导入中」加载态（会改变第 5 节文案）。
